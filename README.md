# AI Agents Laboratory

**Logical role:** AI-agent laboratory.

This repository is the workspace for designing autonomous and semi-autonomous AI agents: roles, agent loops, planning, reflection, delegation, and evaluation.

## Structure

- `agents/` — agent specifications
- `protocols/` — coordination protocols
- `experiments/` — reproducible experiments
- `evaluations/` — tests and results

## Principle

An agent claim should be backed by an observable test or a clearly marked hypothesis.
